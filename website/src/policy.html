Privacy policy
without the mystery.

Last updated: November 7, 2026. SYNTHNET Desktop is designed so an operator can run a local-first hotspot without sending provider credentials to the SYNTHNET website.

What SYNTHNET collects

The desktop application stores the operational information required to run your hotspot, including package activity, masked phone numbers, payment status, voucher records, device sessions, SMS outbox entries, and admin activity. This data is stored on the Windows computer running your installation, inside its local SYNTHNET data folder.

Payment and SMS records may include customer contact details or message content because those records are needed to complete transactions, deliver messages, retry failures, and show the operator what happened. Keep the Windows account and local data folder protected.

Your provider credentials stay yours

Each operator supplies their own credentials. SYNTHNET does not provide, request, or embed a shared payment key, payment secret, SMS token, or sender ID.

  • Payment credentials are entered locally for Courtney Tech. Create and manage them at courtneytech.xyz.
  • SMS credentials are entered locally for SMS.OTS. Create and manage them at sms.ots.co.ke.
  • Credentials are sent only from your desktop app to the provider endpoint configured for that integration.
  • Never paste provider secrets into the public website, WhatsApp, Telegram, GitHub, Vercel, screenshots, or support messages.

What the SYNTHNET website does not do

The public website does not collect payment API keys, payment secrets, SMS tokens, sender IDs, customer phone numbers, M-Pesa PINs, or hotspot passwords. The website reads published release metadata to display releases and downloads. It does not need your provider credentials.

Support email is available for questions, but do not send passwords, API keys, secrets, customer lists, payment PINs, or full transaction exports by email.

Cookies and local storage

The website uses no advertising cookies, analytics trackers, marketing pixels, or third-party profiling tools. A small essential local-storage preference remembers that you dismissed this notice. You can clear it by clearing site data in your browser. The desktop app may keep its own local settings and release-notification marker separately.

Security responsibilities

Use a strong admin password, change the default hotspot password before serving customers, restrict access to the Windows computer, keep Windows and the app updated, and revoke or regenerate provider credentials if you suspect exposure. SYNTHNET cannot protect data from an already-compromised Windows account, malware, insecure backups, or credentials shared by an operator.

Contact

For a security concern, issue, or feature request, contact anonymiketech@gmail.com. Do not include secrets in the first message.
